rdkit 2026.03.5-r1

Purpose:
  RDKit is a C++ and Python toolkit for cheminformatics and molecular machine
  learning. This app provides the RDKit 2026.03.5 Python runtime, shared
  libraries, runtime data, Contrib files, and drawing dependencies.

Usage:
  taf-rdkit python analysis.py
  taf-rdkit python -m rdkit.Chem.ChemUtils.SDFToCSV input.sdf output.csv
  taf-rdkit rdkit-runtime-info
  taf-rdkit rdkit-runtime-info --json

Default and packaged commands:
  python              Default Python 3.12 runtime with RDKit installed.
  python3             Explicit alias for the packaged Python runtime.
  rdkit-runtime-info  Print component versions and capability probes.

Command-mode note:
  RDKit is primarily a library and has no single upstream rdkit executable.
  Use taf-rdkit python script.py for a script file. Do not use
  taf-rdkit script.py, because a non-option-leading argument is interpreted as
  a container executable by TAFFISH command mode.
  Put non-trivial code in a script; shell-rich inline python -c strings are not
  a stable cross-shell interface for this shell-native wrapper.

Core Python capabilities:
  Chem / AllChem       Molecule I/O, SMARTS, reactions, 2D/3D operations.
  Descriptors          Molecular descriptors and property calculators.
  Fingerprints         Morgan, RDKit, atom-pair, torsion, Avalon, and others.
  DataStructs          Similarity and bit-vector operations.
  MolStandardize       Fragment, charge, tautomer, and parent handling.
  Draw                 SVG, PNG, and PDF-capable molecular depiction.
  InChI / FreeSASA     InChI keys and solvent-accessible surface calculations.
  PandasTools          SDF and molecule integration with pandas data frames.
  Contrib              Files retained; SA_Score is the verified module.

Inputs:
  Python scripts       Project analysis code; invoke with explicit python.
  SMILES/SMARTS        Molecule and query strings parsed by RDKit.
  SDF/Mol/PDB files    Common structure formats handled by user code.
  Reaction files       RDKit-supported reaction inputs and SMARTS.

Key outputs:
  Structure files      SDF/Mol/PDB and canonical SMILES chosen by user code.
  Feature tables       Molecular descriptors, fingerprints, and similarities.
  Molecule images      SVG/PNG/PDF depictions generated by RDKit drawing APIs.
  3D structures        Embedded or optimized conformers written by user code.

Platform and resources:
  Native images are built for linux/amd64 and linux/arm64. Large molecule
  collections, fingerprint matrices, conformer ensembles, and pandas tables can
  be CPU- and memory-intensive. Prefer reproducible scripts over interactive use.

Runtime data:
  Core RDKit data and Contrib files are included at /opt/rdkit/share/RDKit.
  Ordinary RDKit operations are offline and need no external database.
  Some Contrib scripts need optional packages or executables not bundled here;
  only SA_Score is part of the verified Contrib surface.
  Project structures, models, PostgreSQL databases, and remote services must be
  supplied or contacted explicitly by user code.

Boundaries:
  The image does not include the PostgreSQL cartridge/server, C++ development
  headers or compilers, Java/C#/JavaScript/KNIME distributions, Jupyter service,
  project compound databases, or trained project models.
